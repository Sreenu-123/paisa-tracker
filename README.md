# 💰 Paisa Tracker

A personal finance tracker built with React, FastAPI, and PostgreSQL.

🚀 **Live Demo:** [Open Paisa Tracker](https://paisa-tracker-1-r0qe.onrender.com)

## ✨ Features
- User registration and login
- Track income and expenses
- Manage transactions
- PostgreSQL database integration
- Responsive React interface

## 🛠️ Tech Stack
- **Frontend:** React, Vite
- **Backend:** FastAPI, Python
- **Database:** PostgreSQL (Neon)
- **Authentication:** JWT
- **Deployment:** Render

## Data Storage

Transactions are stored locally in the browser. Data is not synced across devices and may be lost if browser site data is cleared. This version does not include a backend or cloud database.
