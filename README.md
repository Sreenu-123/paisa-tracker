# Paisa — Personal Finance Tracker

A personal finance tracker built with React and Vite to record income and expenses and view spending summaries in a clean dark-themed dashboard.

![Paisa dashboard](docs/paisa-dashboard.png)

## Features

- Track income and expenses
- View total balance, monthly income, expenses, and savings
- Categorize transactions
- View cash flow and spending breakdown
- Search and filter transactions
- Export transactions to CSV
- Save transaction data in browser `localStorage`

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Lucide React
- Browser `localStorage`

## Data Storage

Transactions are stored locally in the browser. Data is not synced across devices and may be lost if browser site data is cleared. This version does not include a backend or cloud database.
